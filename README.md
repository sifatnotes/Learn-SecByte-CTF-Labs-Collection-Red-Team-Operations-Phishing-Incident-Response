## Introduction

Executing full-scope offensive engagements and mounting defensive incident responses require a granular understanding of every operational phase—from initial reconnaissance and phishing infrastructure deployment to post-compromise lateral movement, forensic triage, and enterprise remediation. Hosted on [Learn SecByte](https://learn.secbyte.org/), this comprehensive collection of CTF challenge labs provides end-to-end practical training across offensive and defensive workflows.

From establishing OPSEC-compliant red team infrastructures, profiling high-value targets, and weaponizing phishing campaigns for initial access, to operating command and control frameworks, pivoting across segmented networks, triaging host/network forensic artifacts, and containing enterprise breaches, these exercises build job-ready security expertise.

## Learning Path

Follow this structured progression path to build complete operational expertise across offensive red team operations and defensive incident response:

1. **Phase 1: Red Team Fundamentals, Target Profiling & Infrastructure** — Understand red team lifecycles, conduct target profiling, and deploy OPSEC redirectors:
   - [Introduction to Red Team Operations](https://learn.secbyte.org/ctf/introduction-to-red-team-operations)
   - [Red Team Methodology and Engagement Lifecycle](https://learn.secbyte.org/ctf/red-team-methodology-and-engagement-lifecycle)
   - [Advanced Reconnaissance and Target Profiling](https://learn.secbyte.org/ctf/advanced-reconnaissance-and-target-profiling)
   - [Red Team Infrastructure and OPSEC Foundations](https://learn.secbyte.org/ctf/red-team-infrastructure-and-opsec-foundations)

2. **Phase 2: Initial Access, C2 Operations & Network Pivoting** — Deliver initial access payloads, establish C2 beacons, and pivot through internal subnets:
   - [Phishing Infrastructure and Initial Access](https://learn.secbyte.org/ctf/phishing-infrastructure-and-initial-access)
   - [Command and Control (C2) Fundamentals](https://learn.secbyte.org/ctf/command-and-control-c2-fundamentals)
   - [Lateral Movement and Pivoting Concepts](https://learn.secbyte.org/ctf/lateral-movement-and-pivoting-concepts)

3. **Phase 3: Digital Forensics & Defensive Incident Response** — Investigate host artifacts, inspect memory dumps, and execute incident containment:
   - [Digital Forensics Fundamentals to Incident Triage](https://learn.secbyte.org/ctf/digital-forensics-fundamentals-to-incident-triage)
   - [Incident Response Fundamentals: From Triage to Containment](https://learn.secbyte.org/ctf/incident-response-fundamentals-from-triage-to-containment)

4. **Phase 4: Full Enterprise Testing & Attack/Defense Capstones** — Execute end-to-end network penetration tests and participate in attack/defense simulations:
   - [Penetration Testing Methodology: From Scope to Validation](https://learn.secbyte.org/ctf/penetration-testing-methodology-from-scope-to-validation)
   - [Enterprise Network Assessment Challenge: End-to-End Lab](https://learn.secbyte.org/ctf/enterprise-network-assessment-challenge-end-to-end-lab)
   - [Cyber 101 Capstone: Full Attack & Defense Scenario](https://learn.secbyte.org/ctf/cyber-101-capstone-full-attack-defense-scenario)

## How to Use the Labs

1. Select a challenge link from the index or category sections above.
2. Read the scenario directives and engagement parameters on [Learn SecByte](https://learn.secbyte.org/).
3. Deploy security toolsets (GoPhish, Sliver C2, Cobalt Strike, Chisel, Volatility, Autopsy, Wireshark, Metasploit) inside an isolated workstation.
4. Execute initial access campaigns, operate C2 frameworks, pivot across networks, analyze digital evidence, contain simulated incidents, and retrieve target flags.
